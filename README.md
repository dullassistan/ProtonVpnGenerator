# ProtonVPN Генератор — C# .NET 8 (WPF)

Графическое приложение для генерации конфигураций ProtonVPN с поддержкой обфускации **AmneziaWG (AWG 1.0, 2.0, 3.0, 3.1)**, **WireSock** и **Clash**.

Создано на основе веб-версии [ProtonVPN Генератор](https://proton-generation.github.io).

---

## 🚀 Основные возможности

1. **Создание и кэширование временного аккаунта ProtonVPN**:
   - Автоматическое получение сессии через официальный Proxy API (`https://proton-api.vercel.app`).
   - Таймер активности сессии (24 часа) с обратным отсчётом в реальном времени.
   - Кэширование сессии и ключей (при повторном открытии сессия восстанавливается автоматически).
   - Кнопка «Сбросить» для мгновенного завершения сессии и очистки кэша.

2. **Выбор серверов и фильтрация по странам**:
   - Быстрые фильтры стран в виде интерактивных чипов (🌍 Все, 🇨🇦 CA, 🇨🇭 CH, 🇯🇵 JP, 🇲🇽 MX, 🇳🇱 NL, 🇳🇴 NO, 🇵🇱 PL, 🇷🇴 RO, 🇸🇬 SG, 🇺🇸 US и др.).
   - Сортировка серверов по минимальной нагрузке.
   - Цветовая индикация нагрузки серверов: 🟢 (<30%), 🟡 (<60%), 🟠 (<90%), 🔴 (≥90%).

3. **Поддержка клиентов**:
   - **AmneziaWG**: классический `.conf` файл с блоками обфускации.
   - **WireSock**: конфигурации с параметрами `Id` (домен), `Ip` (quic/dns), `Ib` (curl/chrome/firefox), тумблерами `Исключить LAN` и `Keepalive`.
   - **Clash**: полный YAML профиль (`.yaml`) с секцией `amnezia-wg-option`.

4. **Параметры обфускации и протокола**:
   - **AWG 1.0**:
     - Пресеты мусорных пакетов: `jc=3, jmin=1, jmax=3`, `jc=30, jmin=10, jmax=30`, либо свой вариант.
     - Кнопка «Случайно» для быстрой рандомизации параметров.
   - **AWG 2.0**:
     - Генерация `I1` ClientHello из любого домена с синтезом валидного QUIC Initial пакета по стандарту RFC 9001.
     - Предустановленная база рандомизированных сигнатур `I1` (кнопка «Случайно»).
     - Поля `I2` – `I5` для кастомных пакетов.
     - Для WireSock — генерация случайного белого домена из проверенного списка.
   - **AWG 3.0**:
     - Тонкая настройка пэддинга и таймаутов (`ContentPaddingAddition`, `MaxHandshakeAttempts`, `KeepaliveTimeout`, `RejectAfterTime`, `RekeyAfterTime`, `RekeyTimeout`).
     - Кнопка «Случайно» для генерации диапазонов.
   - **AWG 3.1**:
     - Тумблеры `Random trailers` и `Disable cookies`.
   - **Сетевые опции**:
     - Выбор Endpoint порта (`80`, `88`, `443`, `1194`, `1224`, `4500`, `4569`, `5060`, `51820`).
     - Настройка `MTU` (по умолчанию 1420).
     - «Исключить LAN» — автоматическое добавление диапазонов исключения локальной сети в `AllowedIPs`.
     - `PersistentKeepalive` — настройка интервала поддержки соединения.

5. **Унифицированный и компактный UI**:
   - Все настройки помещаются в одно адаптивное окно без многоуровневых вложенностей.
   - Центрированные выпадающие списки (включая шапки `Ip:` и `Ib:` для WireSock).
   - Все тумблеры (ToggleSwitch) строго одного размера, но с уникальной цветовой индикацией:
     - AWG 1.0: Индиго (`#4F46E5`)
     - AWG 2.0: Изумрудный (`#10B981`)
     - AWG 3.0: Фиолетовый (`#8B5CF6`)
     - AWG 3.1: Янтарный (`#F59E0B`)
     - Исключить LAN: Бирюзовый (`#06B6D4`)
     - PersistentKeepalive: Коралловый (`#F43F5E`)
   - Вспомогательные кнопки настроек имеют единую высоту 30px и индивидуальные цвета.
   - Основные кнопки экспорта имеют единую высоту 38px.
   - Стартовая подсказка `# Выберите параметры слева` при запуске программы и при сбросе сессии.
   - Строка авторства по центру шапки: `Thanks @llimonix, @WARP 1_1_1._1`.

6. **Экспорт и скачивание**:
   - «Копировать текст»: мгновенное копирование в буфер обмена.
   - «Скачать файл»: сохранение одиночного `.conf` или `.yaml`.
   - «Скачать по странам (.zip)»: пакетная выгрузка оптимального сервера с минимальной нагрузкой для каждой доступной страны.
   - «Скачать все (.zip)»: выгрузка всех доступных серверов в один архив.

## 🛠️ Сборка и запуск

### Быстрый запуск готовой программы
Скомпилированная и опубликованная программа находится в папке:
`C:\Генератор\ProtonVpnGenerator\Release\ProtonVpnGenerator.exe`

Просто запустите файл `ProtonVpnGenerator.exe`.

### Открытие в Visual Studio
1. Запустите Visual Studio.
2. Откройте решение `C:\Генератор\ProtonVpnGenerator\ProtonVpnGenerator.sln`.
3. Нажмите **F5** (или Ctrl+F5) для запуска.

### Сборка через терминал
```bash
cd C:\Генератор\ProtonVpnGenerator
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o Release
```

### Запуск тестов
```bash
dotnet test C:\Генератор\ProtonVpnGenerator.Tests\ProtonVpnGenerator.Tests.csproj
```
